# Providers

The mock collector proves the normalized contract. The Anthropic browser collector reads the Claude Settings → Usage page using a dedicated local Chromium profile per account. Run `claude login` once for each account, then `claude sync` as a one-shot refresh. The parser publishes only displayed session and weekly all-model percentages. Missing meters become unknown buckets, so routing will not mistake absent measurements for free capacity. Reset times remain null until a reliable provider-reported instant can be extracted. Login and parsing stay on the Mac; only normalized snapshots reach the service. The adapter still needs validation with a signed-in page and a scheduler. OpenAI and xAI can later use the same snapshot contract without adding columns to the usage schema.
